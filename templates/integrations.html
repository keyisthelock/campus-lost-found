A SAS token is a temporary access credential. You choose its permissions and expiry in Azure.

  1. 01Open your existing private container in Azure Portal.
  2. 02Generate a container SAS with HTTPS and an expiry within 24 hours.
  3. 03Grant read to test; add create/write to copy. Leave list and delete off.
  4. 04Paste the token here and select Test connection.
What about Azure SQL?

Azure SQL uses the server's DATABASE_URL environment variable. Students do not enter database passwords here. Connection strings are never displayed.

What happens to my credentials?

They are discarded after each operation, never saved in the database, browser storage or cookies. Re-enter them for a later action. Your original photograph stays local even if Azure fails.
